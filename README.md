## 🧾 Overview

**HireHelper** is an on-demand task assistance platform that connects individuals who **need help** with others willing to **offer help**.  
It enables users to **post tasks**, **browse jobs**, **send or receive help requests**, and **manage tasks** within a secure, user-friendly environment.

The platform focuses on **real-time coordination**, **secure OTP-based authentication**, and **a streamlined dashboard** for easy management.

---

## 🧩 Core Objectives

- **Simplify hiring and coordination** between users.
- **Ensure security** through email-based OTP verification.
- **Enable task management** — create, view, accept, or track tasks.
- **Provide real-time notifications** and updates.
- **Maintain clean UI/UX** for both desktop and mobile users.

---

## 🚀 Key Features

|           Feature                 |                        Description                                         |
|-----------------------------------|----------------------------------------------------------------------------|
| **Post & Find Tasks**             | Users can create tasks with details and browse public tasks.               |
| **Request & Notification System** | Send requests to assist; get real-time updates when requests are accepted. |
| **Secure Login System**           | OTP verification ensures user safety and authenticity.                     |
| **Dashboard Management**          | Centralized control to view all tasks, requests, and updates.              |
| **Profile Customization**         | Edit bio, language, and personal information.                              |

## 📄 Functional Pages

|         Page          |                          Description                                     |
|-----------------------|--------------------------------------------------------------------------|
| **Registration Page** | New users can create an account using their email.                       |
| **Login Page**        | Users authenticate with credentials or Google sign-in.                   |
| **OTP Page**          | Email-based verification for secure access.                              |
| **Home / Dashboard**  | Central hub for navigation and task overview.                            |
| **Feed Page**         | Displays tasks posted by other users; includes search and filters.       |
| **My Task Page**      | Lists all tasks created by the current user.                             |
| **Request Page**      | Shows incoming help requests with Accept/Decline options.                |
| **My Request Page**   | Displays requests sent to others with live status.                       |
| **Add Task Page**     | Allows creation of new tasks with title, description, and location.      |
| **Settings Page**     | Update account preferences and profile details.                          |

## 🗄️ Database Structure

|    Collection     |                  Purpose                         |
|-------------------|--------------------------------------------------|
| **Users**         | Stores user credentials and profile details.     |
| **Tasks**         | Contains all task entries created by users.      |
| **Requests**      | Manages user requests for helping with tasks.    |
| **AcceptedTasks** | Records accepted or in-progress tasks.           |
| **Notifications** | Stores system-generated notifications for users. |
